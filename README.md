# 📚 Online Bookstore SQL Project

A PostgreSQL-based relational database for managing an online bookstore. 
This project includes database schema creation, data import from CSV files, and a collection of SQL queries for data analysis and reporting.

## ⚙️ Schema Overview

- **Books**: book details (title, author, genre, price, stock, etc.)
- **Customers**: customer information
- **Orders**: links books and customers with order details
